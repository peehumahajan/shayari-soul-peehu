# Ishq-e-Shayari App

Create a fully functional, production-ready mobile application named “Ishq-e-Shayari” designed for Android (Play Store ready). The app should be modern, aesthetic, smooth, and optimized for performance with zero bugs or crashes.



Core Features:



1. User Authentication

   

   - Sign up / Login (Email, Google)

   - Secure authentication system

   - User profiles with profile picture, bio, and username



2. Shayari Posting System

   

   - Users can write and post their own shayari (text-based)

   - Option to add categories (love, sad, friendship, motivation, etc.)

   - Clean and beautiful UI for reading shayari (focus on typography)



3. Like & Engagement

   

   - Users can like shayari

   - Like count visible

   - Save/bookmark option

   - Comment section (optional but clean and simple)



4. Reel (Video Shayari) Feature

   

   - Users can upload short videos (reels) where they recite their own shayari

   - Strict content filtering:

     - Only allow original shayari content

     - Block/remove promotional, spam, or irrelevant videos

     - Add basic AI/moderation system or reporting feature

   - Vertical scrolling reel feed (like Instagram Reels but minimal)



5. Content Moderation

   

   - Report button for inappropriate content

   - Admin panel (basic) to remove spam or promotion videos

   - AI-based keyword filtering for spam detection



6. Trending & Viral System

   

   - “Trending Shayari” section based on likes + engagement

   - “New & Fresh” section

   - Smart algorithm to boost high-quality content



7. UI/UX Design

   

   - Romantic, aesthetic theme (soft pink, black, gold tones)

   - Smooth animations and transitions

   - Clean typography (Hindi/Urdu-friendly fonts)

   - Dark mode support



8. Monetization (Important)

   

   - Google AdMob integration (banner + rewarded ads)

   - Optional premium feature:

     - Remove ads

     - Highlight user shayari

   - Ensure Play Store monetization compliance



9. Performance & Security

   

   - Fast loading

   - Optimized backend (Firebase or Node.js)

   - Secure database (Firestore or MongoDB)

   - No crashes, no lag, no bugs



10. Play Store Ready



- App icon, splash screen

- Proper permissions (camera, storage for reels)

- Privacy policy included

- Fully compliant with Play Store policies



11. Branding & Emotional Connect



- App should feel poetic and emotional

- Create a strong identity so users feel “Ishq” (love/connection) with the app

- Add onboarding screens explaining the vibe of shayari



12. Footer Credit



- At the end of the app (settings/about section), display:

  “Made by Shayar Peehu”



Goal:



The app should be designed to go viral, encourage creativity, and build a strong community of shayari lovers. It should feel unique, addictive, and emotionally engaging so users keep coming back and sharing content.



Deliverables:



- Full frontend + backend code

- Clean folder structure

- Deployment-ready build

- Instructions to upload on Play Store

- No errors, no bugs, fully working app



Ensure the app is visually stunning, smooth, scalable, and ready for real users.
